راه‌اندازی استخراج کد ایموجی پرمیوم با همان اکانت پشتیبان

۱) در فایل requirements.txt پروژه این خط را اضافه کن (بقیه وابستگی‌ها را پاک نکن):
   Telethon>=1.36,<2

۲) برای ساخت نشست اکانت پشتیبان، فایل make_userbot_session.py را روی یک دستگاه مطمئن اجرا کن:
   pip install "Telethon>=1.36,<2"
   python make_userbot_session.py
   شماره همان اکانت پشتیبانی، کد ورود تلگرام و در صورت فعال بودن رمز دومرحله‌ای را وارد کن.
   اسکریپت یک USERBOT_SESSION چاپ می‌کند. این مقدار مثل رمز عبور است؛ آن را برای هیچ‌کس نفرست.

۳) در Railway > پروژه > Variables این سه متغیر را اضافه کن:
   TELEGRAM_API_ID      = API ID از my.telegram.org
   TELEGRAM_API_HASH    = API HASH از my.telegram.org
   USERBOT_SESSION      = خروجی محرمانه مرحله ۲

۴) مطمئن شو همان اکانت در ربات دسترسی «پنل» و «مینی‌اپ پشتیبانی» را دارد.
   کد هنگام روشن شدن شناسه اکانت را بررسی می‌کند و اگر این دو دسترسی را نداشته باشد، یوزربات را فعال نمی‌کند.

۵) bot.py جدید را جایگزین نسخه قبلی کن و Deploy بزن.

استفاده:
- در پی‌وی یا گروه، روی پیام دارای ایموجی پرمیوم ریپلای کن.
- بنویس: .کدشو میخوام
- یوزربات همان اکانت، شناسه ایموجی(ها) را در پاسخ می‌فرستد.

نکات امنیتی:
- USERBOT_SESSION دسترسی ورود به اکانت تلگرام را می‌دهد؛ آن را در چت، گروه، GitHub یا کد عمومی قرار نده.
- فقط در Railway Variables ذخیره‌اش کن و مخزن GitHub را خصوصی نگه دار.
- اگر نشست افشا شد، از بخش Devices تلگرام نشست ناشناس را خاتمه بده و نشست جدید بساز.
- این قابلیت با Bot API به‌تنهایی انجام نمی‌شود؛ به Telethon و نشست همان اکانت پشتیبان نیاز دارد.
